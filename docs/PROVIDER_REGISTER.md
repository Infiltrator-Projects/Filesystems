## Continuing the register

Edit the JSON after qualifying a change. Preserve earlier evidence and add the relevant SHA, regression, workflow, release or media hash. Run `python3 tools/render_provider_register.py` to recalculate the totals and produce this table. Use `--check` to verify both files agree. The historical migration matrices remain available in repository history.
